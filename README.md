# Барбер Афанди — сайт-лендинг

Одностраничный лендинг барбершопа: услуги, мастера, галерея, отзывы, контакты и карта.

Статический сайт — без сборки и сервера.

## Как открыть

Дважды кликни по `index.html` — сайт откроется в браузере.

## Как поменять тексты и цены

Всё содержимое лежит в `site-data.js` (тексты, цены, контакты, цвета, координаты карты).
Файлы `index.html`, `styles.css` и `app.js` менять не нужно.
